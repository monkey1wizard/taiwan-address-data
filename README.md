# taiwan-address-lookup

有鑒於地址轉經緯度是一個很重要的需求，但是很少有可以離線大量查詢的版本，因此這個專案希望可以滿足這需求，讓大家可以更容易把門牌轉經緯度融合進自己的服務中。

`roads/` 目錄下以「縣市代碼-道路名」分檔存放全台門牌座標（WGS84 經緯度），可直接離線查詢，不需呼叫線上 API。

## 資料來源

各縣市門牌座標來自政府開放資料平台（[data.gov.tw](https://data.gov.tw/) / [data.nat.gov.tw](https://data.nat.gov.tw/)）及各縣市自有開放資料平台所發布的「門牌位置／門牌坐標」資料集。原始座標為 TWD97/TM2（EPSG:3826），經 `pyproj` 轉換為 WGS84（EPSG:4326）。

> 早期版本的台中市等資料來自 [TGOS](https://tgos.nat.gov.tw/)。

## 資料更新工具

`update_addresses.py` 是設定驅動（config-driven）的多縣市門牌更新器：自動下載指定縣市的門牌座標資料集、轉換座標、拆解路段，並重建 `roads/` 下該縣市的所有 CSV。

```bash
pip install requests pyproj openpyxl   # openpyxl 僅 XLSX-only 縣市需要

python scripts/update_addresses.py --list      # 列出已設定的縣市
python scripts/update_addresses.py 新北市       # 更新單一縣市
python scripts/update_addresses.py --all       # 更新全部已設定縣市
```

⚠️ 每次執行會**先刪除該縣市現有的 `{代碼}-*.csv`，再用最新下載的資料整批重建**（非增量合併）。因為各縣市開放資料皆為「全量現況門牌」（完整全集，非當月異動），整批取代是安全的，不會與舊資料產生鴻溝。

## 尚未支援的縣市

以下 4 縣市目前在政府開放資料中**查無可批次下載的門牌座標檔**，僅有單筆查詢系統或付費申購，故未納入：

| 縣市 | 現況 |
|------|------|
| 宜蘭縣 | 僅 lifemap 門牌比對工具（一次限 50 筆）或計畫處付費申購 |
| 南投縣 | 開放資料平台查無門牌座標集 |
| 連江縣 | 開放資料平台地政分類 0 筆，無門牌資料 |
| 嘉義市 | 僅「門牌整編對照表」（新舊門牌對照，無座標欄） |

> 中央的臺灣通用電子地圖雖有涵蓋全 22 縣市的門牌向量圖層（座標即 TWD97），但僅開放政府／學術單位透過 WFS 取用，一般開放資料版只有圖磚而非向量。
