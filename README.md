# taiwan-address-lookup

有鑒於地址轉經緯度是一個很重要的需求，但是很少有可以離線大量查詢的版本，因此這個專案希望可以滿足這需求，讓大家可以更容易把門牌轉經緯度融合進自己的服務中。

`roads/` 目錄下以「縣市代碼-道路名」分檔存放全台門牌座標（WGS84 經緯度），可直接離線查詢，不需呼叫線上 API。

## 資料來源

各縣市門牌座標來自政府開放資料平台（[data.gov.tw](https://data.gov.tw/) / [data.nat.gov.tw](https://data.nat.gov.tw/)）及各縣市自有開放資料平台所發布的「門牌位置／門牌坐標」資料集。原始座標為 TWD97/TM2（EPSG:3826），經 `pyproj` 轉換為 WGS84（EPSG:4326）。

> 早期版本的台中市等資料來自 [TGOS](https://tgos.nat.gov.tw/)。

## 目錄結構

```txt
taiwan-address-lookup/
├── address.html / address.js   # 前端查詢介面（直接開啟 address.html 即可使用）
├── area_custom.csv             # 最高優先：人工補丁（2 列）
├── area_2015.csv               # 2015 年行政區改制（員林市/頭份市升格 + NLSC 現況村里）
├── area_2014.csv               # 2014 年行政區快照（ROC 2014 行政區改制後）
├── area_2010.csv               # 舊名對照（供解析含舊縣市名的歷史地址）
├── area_1984.csv               # 更早舊名對照
├── road.csv                    # 路名索引（縣市代碼 ↔ 路名，由 build_road_index.py 產生）
├── roads/                      # 門牌座標資料，一檔一路：{縣市代碼}-{路名}.csv
└── scripts/
    ├── update_addresses.py     # 主更新器：下載各縣市門牌資料並重建 roads/
    ├── build_road_index.py     # 從 roads/ 重建 road.csv 索引
    ├── build_area_2015.py      # 從 roads/ 提取新行政區映射，產生 area_2015.csv
    └── probe_counties.py       # 工具：探查 data.gov.tw 各縣市資料集
```

### area\_\*.csv 疊層機制

`address.js` 載入多個 area CSV，優先序為：**custom > 2015 > 2014 > 2010 > 1984**。
後面的年份不會被刪除，目的是讓含舊行政區名（如「臺北縣板橋市」）的歷史地址仍能解析。每次有新縣市改制或新增村里時，只需新增一個年份層，不修改舊檔。

### road.csv 索引

`road.csv` 是 `address.js` 在讀取 `roads/{縣市代碼}-{路名}.csv` 之前的路名查詢索引。更新 `roads/` 後必須同步更新此索引；`update_addresses.py` 在每次縣市更新後會自動呼叫 `build_road_index.py`。若要單獨重建：

```bash
python scripts/build_road_index.py
```

## 資料更新工具

`scripts/update_addresses.py` 是設定驅動（config-driven）的多縣市門牌更新器：自動下載指定縣市的門牌座標資料集、轉換座標、拆解路段，並重建 `roads/` 下該縣市的所有 CSV，完成後自動同步 `road.csv` 索引。

```bash
pip install requests pyproj openpyxl   # openpyxl 僅 XLSX-only 縣市需要

python scripts/update_addresses.py --list      # 列出已設定的縣市
python scripts/update_addresses.py 新北市       # 更新單一縣市
python scripts/update_addresses.py --all       # 更新全部已設定縣市
```

⚠️ 每次執行會**先刪除該縣市現有的 `{代碼}-*.csv`，再用最新下載的資料整批重建**（非增量合併）。因為各縣市開放資料皆為「全量現況門牌」（完整全集，非當月異動），整批取代是安全的，不會與舊資料產生鴻溝。

## 尚未支援的縣市

以下 4 縣市目前在政府開放資料中**查無可批次下載的門牌座標檔**，僅有單筆查詢系統或付費申購，故未納入：

| 縣市 | 現況 |
| ---- | ---- |
| 宜蘭縣 | 僅 lifemap 門牌比對工具（一次限 50 筆）或計畫處付費申購 |
| 南投縣 | 開放資料平台查無門牌座標集 |
| 連江縣 | 開放資料平台地政分類 0 筆，無門牌資料 |
| 嘉義市 | 僅「門牌整編對照表」（新舊門牌對照，無座標欄） |

> 中央的臺灣通用電子地圖雖有涵蓋全 22 縣市的門牌向量圖層（座標即 TWD97），但僅開放政府／學術單位透過 WFS 取用，一般開放資料版只有圖磚而非向量。
