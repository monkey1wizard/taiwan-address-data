## 執行中發現的問題

- **Windows 本機缺少 69 個路檔。** Git 追蹤的 69 個路檔檔名含「?」，在 index 中標記為 skip-worktree，所以 Windows 工作樹沒有這些檔案。更新器重建 `road.csv` 時只掃描工作樹，結果少了 72 筆其他縣市的路名。資料提交改用 Git 追蹤的檔名重建 `road.csv`。這個方法套用在 `508edae05` 的檔案清單時，能逐字重現當時的 `road.csv`。
- **更新器刪不到含「?」的舊路檔。** `roads/10004-祥喜?.csv` 是 2016 年的 1 列資料，新來源已沒有這條路。更新器在 Windows 看不到這個檔，所以沒有刪除。資料提交以 `git rm --cached --sparse` 移除。
- **新竹縣路名變動。** `road.csv` 只有新竹縣 4 筆變動：「文山路_頭山段」改為「文山路犂頭山段」，「文林村９D-文山路」改為「文林村９鄰文山路」，「義民路─段」改為「義民路―段」，並刪除「祥喜?」。「義民路―段」的「―」是來源原字 U+2015。
