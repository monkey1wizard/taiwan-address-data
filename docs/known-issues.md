# 已知問題

本頁說明目前已知的限制。歷史數字依原紀錄的資料版本與規則引用，本次文件整理沒有重跑資料稽核，也沒有修正地址或座標。

## 新竹縣地址格式

- **結果與影響：** 2026-10-08，下游稽核使用以下固定地址版本。新竹縣 262,762 列全部判為 `invalid_address`，無法依當時規則建立地址鍵。這不表示所有用途都無法使用，也不代表其他資料版本有相同結果。
- **資料版本：** `taiwan-address-data` 提交 `3ff9be0265b22a4910abf2bd4e3e96c7653fb6f0`。
- **歷史驗收：** 下游 R05-6 在 2026-10-09 判定該工作包通過驗收，並未因此修好新竹縣地址資料。
- **證據：** [R05 執行紀錄](https://github.com/monkey1wizard/taiwan-lvr-geodata/blob/c23c03d518bade7282c716931a71b90d61a3e792/docs/records/R05%E5%9F%B7%E8%A1%8C%E7%B4%80%E9%8C%84.md)中的 R05-3、R05-6。連結固定下游提交 `c23c03d518bade7282c716931a71b90d61a3e792`，本次在本機核對該版本，未連線測試網址。
- **原因：** 政府的 Big5 CSV 匯出把「鄰／巷／弄／號」寫成 `D-`／`G-`／`H-`／`I-`，Big5 以外的字寫成「?」。同一版的 XLSX 與 JSON 是正確的。
- **目前狀態：** 2026-10-13 已修正。更新器改讀 XLSX，程式提交 `223fec5a6`，資料提交 `216accf2f`。路檔已沒有字母標記與「?」。仍有 7,033 列村里對不上代碼，原因見[重跑紀錄](records/2026-10-13-新竹澎湖金門重跑.md)。下游尚未重新釘選。

## 澎湖與金門座標

- **結果與影響：** 下游 R05-5 的新舊座標比較發現 6 筆地址鍵偏移超過 100 km，澎湖、金門各 3 筆。紀錄指出經度約差 2 度，緯度一致。這是歷史比較結果，不代表已逐筆判定兩縣所有座標。
- **原因：** 2026-10-13 確認。兩縣來源使用 TWD97 TM2 119 度分帶，更新器卻用預設的 121 度分帶換算，所以經度剛好偏東 2 度。
- **資料版本與日期：** 地址資料為 `3ff9be0265b22a4910abf2bd4e3e96c7653fb6f0`。下游在 2026-10-09 的 R05-9 決定暫停兩縣定位，保留原始觀測，不在下游修正地址資料。
- **證據：** [R05 執行紀錄](https://github.com/monkey1wizard/taiwan-lvr-geodata/blob/c23c03d518bade7282c716931a71b90d61a3e792/docs/records/R05%E5%9F%B7%E8%A1%8C%E7%B4%80%E9%8C%84.md)中的 R05-5 卡外發現、R05-9 與 R05-6 比較結果。原量測、命令及驗收紀錄仍保留在該文件。
- **目前狀態：** 2026-10-13 已修正。兩縣改用 `EPSG:3825`，程式提交 `223fec5a6`，資料提交 `216accf2f`。金門縣逐列確認只差 2 度。澎湖縣有 549 列另有移動，判定為來源 2026-10-05 改版。詳見[重跑紀錄](records/2026-10-13-新竹澎湖金門重跑.md)。下游的暫停定位仍有效，要由擁有者在重新釘選後決定是否解除。

## Windows 本機的含「?」路檔

- **結果與影響：** 69 個 Git 追蹤的路檔檔名含「?」，在 Windows 工作樹中不存在。在 Windows 執行更新器時，重建的 `road.csv` 會少掉這些路名，也刪不到該縣含「?」的舊路檔。在 Linux 執行的每月 workflow 不受影響。
- **版本與日期：** 2026-10-13 重跑三縣時發現。
- **證據：** [重跑紀錄](records/2026-10-13-新竹澎湖金門重跑.md)的「執行中發現的問題」。
- **目前狀態：** 未修正程式。在 Windows 重跑後，要以 Git 追蹤的檔名重建 `road.csv`，並手動移除該縣含「?」的舊路檔。2026-10-13 缺字還原後，含「?」的路檔從 69 個減為 35 個：宜蘭縣 16、雲林縣 7、新北市 5、臺南市 3、苗栗縣、南投縣、嘉義縣與臺中市各 1。

## 缺字「?」

- **結果與影響：** 政府匯出檔把 Big5 以外的字寫成「?」。這會讓路名、村里名錯誤，村里也對不上代碼。
- **版本與日期：** 2026-10-13 調查並修正彰化縣、屏東縣、臺東縣、花蓮縣、高雄市。程式與表格提交 `4e9e5fe40`，資料提交 `83554e68a`。
- **證據：** [缺字還原企劃](plans/缺字還原企劃.md)與[缺字還原紀錄](records/2026-10-13-缺字還原.md)。
- **未解項目：** 彰化縣「上林路頂?段」67 列、「田?巷」72 列、「頂?巷」6 列，屏東縣「麥?巷」22 列。官方路名清單沒有段名與巷名，所以無法確定原字。號欄的註記文字不還原。新北市、臺北市、金門縣、宜蘭縣等其他縣市的「?」尚未處理。
- **私用區字元：** 新竹縣 63 列為「上里」，來源本身就是私用區字元，尚未查證，所以沒有轉換。
- **擴充 B 字：** 高雄市「山𨻶路」的「𨻶」是 U+28EF6。部分字型與系統無法顯示。
- **兩種寫法並存：** 彰化縣「山腳路」與「山脚路」在員林、大村、社頭都同時存在。來源本身就是如此，本專案不合併。
- **目前狀態：** 五縣已還原。其他縣市與上述未解項目尚待處理。
