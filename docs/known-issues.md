# 已知問題

本頁只列目前仍存在的問題。已解決問題的經過見 [records](records/) 內的執行紀錄。

## 村里代碼

- **結果與影響：** 更新器找不到村里名稱對應的代碼時，`VILLAGE` 會寫成 `{鄉鎮市區代碼}-000`。2026-10-14 臺中市重跑後，路檔已沒有這種列。之後來源若出現新村里名稱，仍會再產生。
- **代碼差異：** 國土測繪中心與 `area_2014.csv` 有 7 個村里代碼不同，都在臺南市官田區與關廟區。路檔沿用 2014 檔的代碼。
- **拆里後的資料：** 臺南市官田區東西庄里依擁有者查得的國土測繪中心代碼寫成 `6701000-016`。2026 年 4 月拆回東庄里與西庄里，代碼為 017 與 018。臺南市最新來源仍是 114 年版。
- **目前狀態：** 臺南市發布拆里後的資料時，需確認東庄里與西庄里能對上代碼。

## 字元顯示與寫法

- **擴充 B 字：** 部分路名使用擴充 B 區的字，例如高雄市「山𨻶路」的 U+28EF6、新北市「𫙮魚坑路」的 U+2B66E，以及桃園市龍潭區地區「𰫕粑崠」的 U+30AD5。部分字型與系統無法顯示。
- **兩種寫法並存：** 彰化縣「山腳路」與「山脚路」在員林、大村、社頭都同時存在。來源本身就是如此，本專案不合併。

## 更新流程的剩餘風險

- **結果與影響：** 更新器先寫暫存目錄再替換，替換失敗會還原舊檔。但程序若在移動檔案的那幾秒內被強制終止，仍可能留下部分成果。
- **實例：** 2026-10-13 重跑屏東縣時，舊版更新器在寫檔途中被中斷，1,678 個舊路檔已刪除，只寫回 66 個。這是改用暫存目錄前的情況，見[全縣市缺字紀錄](records/2026-10-13-全縣市缺字.md)。
- **證據：** [更新器](../scripts/update_addresses.py)及[月更新設定](../.github/workflows/monthly-update.yml)。通知中的 `PUSHED` 取自檔案差異，不是推送成功證明。
- **目前狀態：** workflow 已改為只在所有選中縣市都成功時提交。臺中市的 Google Drive 下載尚未在 GitHub Actions 實際執行過，要等下次月更新或手動觸發才能確認。
